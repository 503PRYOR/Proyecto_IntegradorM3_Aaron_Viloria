    Acerca de

    Tesla Chat es una Single Page Application para conversar con Nikola Tesla. Las respuestas las genera Google Gemini a través de una Vercel Serverless Function, de modo que la API key nunca llega al navegador.

    La conversación se guarda solo mientras la página siga abierta: si recargas, Tesla olvida todo.

    Tecnologías

    HTML, CSS (mobile-first), JavaScript modular, History API, Gemini API, Vercel y Vitest.
